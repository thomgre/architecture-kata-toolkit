# Architecture Diagram

**Visualize the complete architecture in a detailed diagram**

The final diagram we create has a lower level of abstraction. The diagram should contain [physical components](https://github.com/thomgre/architecture-kata-toolkit/blob/main/04%20Diagramming/References/architecture-design-components.md) such as microservices, databases, caches, reverse proxies, data warehouses, etc. It should be detailed enough to describe the overall solution.

> Keep in mind that we have limited time for diagramming and it's easy to underestimate!
